# NNN — Short name of the bug

- **Project / files:** where it happened (keep paths so it can be found again)
- **Stack:** e.g. React 19, motion 12, Tailwind 4
- **Date:** YYYY-MM-DD

## Symptom
What the user saw, in their words if possible.

## Conditions
What makes it appear and disappear: breakpoint, scroll position, host, mode,
browser. Which conditions did *not* matter.

## Measurement
The numbers that located the cause (visible / firstFrame / settled, inset
sizes, computed styles). Include how they were taken.

## Cause
The mechanism, in one paragraph.

## Didn't work
Each attempted fix that left the measurement unchanged, and why it couldn't
have worked. These save the next person the most time.

## Fix
What changed, with a minimal code shape.

## Rule
The project-neutral lesson, one or two sentences. Promote it into SKILL.md
(Principles, Rules or Checklist) if it's new.
